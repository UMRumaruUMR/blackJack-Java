# BlackJack (Java)

コンソールで遊べるシンプルなブラックジャックゲームです。(日本語UI)
콘솔에서 즐기는 간단한 블랙잭 게임입니다. (일본어 UI)

---

## 日本語

### 遊び方 (Windows / exe版)
1. Releases から `BlackJack-win.zip` をダウンロードします。
2. 解凍して `start.bat` を実行します。
3. SmartScreen の警告が出た場合は「詳細情報 → 実行」を選んでください。

### Java がインストール済みの場合
```
javac -encoding UTF-8 blackJack.java
java blackJack
```

### ゲームのルール
- カードの合計が21以下で、ディーラーより21に近ければ勝ちです。
- Aは1または11として数えられます。J・Q・Kは10です。
- プレイヤーは21未満の間、何枚でもカードを引けます。
- ディーラーは21との差が大きい場合、1枚追加で引くことがあります。
- ディーラーとプレイヤーの両方が21を超えた場合は引き分けです。
- ベット入力で `0` を入力するとメニューに戻ります。

### 注意事項
- 文字化けする場合は Windows Terminal で実行してください。
- exe は Windows 専用です。

## 한국어

### 실행 방법 (Windows / exe)
1. Releases에서 `BlackJack-win.zip`을 다운로드합니다.
2. 압축을 풀고 `start.bat`을 실행합니다.
3. SmartScreen 경고가 나오면 「추가 정보 → 실행」을 선택하세요.

### Java가 설치되어 있는 경우
```
javac -encoding UTF-8 blackJack.java
java blackJack
```

### 게임 규칙
- 카드 합계가 21 이하이면서 딜러보다 21에 가까우면 승리합니다.
- A는 1 또는 11, J·Q·K는 10으로 계산합니다.
- 플레이어는 합계가 21 미만인 동안 카드를 계속 뽑을 수 있습니다.
- 딜러는 21과의 차이가 클 경우 한 장을 추가로 뽑을 수 있습니다.
- 딜러와 플레이어가 모두 21을 넘으면 무승부입니다.
- 베팅 입력에서 `0`을 입력하면 메뉴로 돌아갑니다.

### 주의
- 글자가 깨지면 Windows Terminal에서 실행해 주세요.
- exe는 Windows 전용입니다.
